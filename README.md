A tiny program that writes one line of wedding vows for a robot couple
to a text file. The vow is a single line of at most 160 characters:
the robot takes its partner and accepts the terms and conditions —
all 4,096 pages of them — without reading a single word.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (`OUTPUT_DIR` overrides the
directory). Running it twice produces byte-identical output.
